# مراجعة شريحة حزمة التشغيل

## ما يتغير فعليًا
يتحوّل build من واجهة وحدها إلى `dist/client/` و`dist/server.mjs` و`dist/manifest.json`. يشغّل `npm start` حزمة Node المبنية في وضع production بدل تشغيل TypeScript المصدر. يحدد الخادم static frontend نسبةً إلى ملفه لا إلى مجلد التشغيل، ويُحمَّل Vite عند التطوير فقط. هذه **حزمة مرشحة للمراجعة المحلية**؛ لا تعديل إعدادات Hostinger ولا مشروع سحابي ولا نشر إنتاجي.

مسارات AI القائمة ترفض الطلبات صراحة، وحاجز إعداد المدير لا يقرأ مفتاحًا ولا يدّعي مصادقة. لا API تسجيل دخول أو مزامنة سحابية صورية. مسارات API المجهولة تعيد JSON 404؛ لا تُقدَّم ملفات الخادم من مساحة static. مسار واجهة غير امتدادي يمكنه الرجوع إلى SPA.

## إعادة الاختبار
```sh
npm test
npm run lint
npm run build
npm run test:runtime
# المعاينة المطلوبة للمراجع هي الخادم المبني، لا Vite preview:
PORT=4182 npm start
# من طرفية أخرى:
PREVIEW_URL=http://127.0.0.1:4182 E2E_ARTIFACT_DIR=/tmp/noon-foundation-e2e npm run test:e2e
```

استخدم الاعتماديات المطابقة لـ`bun.lock`؛ لا يوجد package-lock ولا يجوز الادعاء بأن npm ci اختُبر. هذه الجولة تستخدم node_modules الموجودة؛ التثبيت النظيف المقفل بالكامل شرط قبول reproducibility لاحق وليس نتيجة مثبتة هنا. اختبار runtime يعتمد build سابقًا؛ unit لا يعتمد dist. لا تشغّل أي اختبار رفع أو AI على نطاق الإنتاج.

## البصمة وحدودها
manifest يحوي SHA256 وأحجام ملفات الحزمة، ومعرّف commit وشجرة HEAD وحالة dirty وسجل Git الخام بصيغة porcelain مع فواصل NUL. إذا كانت الشجرة معدلة فلا يثبت commit وحده مصدر الناتج. بعد تثبيت SHA تُبنى الحزمة من الحالة النظيفة، ويُحفظ manifest خارج المستودع مع سجل الاختبارات ويُطابق ما تقدمه المعاينة.

manifest ليس توقيعًا من جهة الاستضافة ولا برهان منشأ إنتاج؛ بيانات Git فيه تقرير محلي. يشمل `dist`، ولا يشمل جميع node_modules أو إعدادات runtime أو كل الملفات اللازمة للنشر. يلزم Node وdependencies وقت التشغيل؛ لا تسمِّ dist حزمة مستقلة بلا اعتماديات. لا تُنقل بيانات بيئة أو أسرار إلى manifest.

اختبار runtime يطلق عملية Node محلية من cwd خارجي ويطابق manifest والأصول وhealth وحجب AI وحماية ملفات الخادم. browser يستخدم ملفات اصطناعية وسياقات Chromium جديدة، مع محاكاة هاتف، وليس اختبار جهاز حقيقي. اتصالات الخطوط الخارجية القائمة لا تُقدَّم على أنها غياب تام للشبكة. تحذيرا حجم chunk وإعداد Vite القديم قيدان معروفان.

## موانع القبول الإنتاجي
مصدر الحزمة الحية الكامل وartifact rollback غير مثبتين؛ PR الـPDF متعارض مع main؛ لم يُعتمد أساس الإصدار النهائي، ولم تُجرّب هذه الحزمة على staging Hostinger. مراجعة مستقلة محلية لا تمنح موافقة إنتاج. تعتمد أي خطوة نشر على إغلاق هذه الموانع وشرط جينو المباشر الموثق في V1-ACCEPTANCE.md.
