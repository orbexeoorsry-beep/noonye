**نطاق الفحص:** قراءة فقط لـ`/workspace/noonye`؛ مقارنة `126bee8` وامتداده `116268b` مع `main` الحقيقي `5db0ce9`، والسلف المشترك `2e7e73b`. لم تُعدّل الشيفرة أو refs الإنتاج، ولم يحدث اتصال شبكي أو تشغيل متصفح. الملف محفوظ خارج المستودع كما طُلب.

## خلاصة تنفيذية

`main` متقدم بأربعة commits بعيدة عن السلف المشترك، وليس مجرد إصلاح لحزمة نشر: يضيف feature flags، ثم i18n إنجليزية، ثم مسار تشغيل Hostinger، ثم تغليف runtime مع assets الإنتاجية. هناك عمل PDF/تعلم/اختبارات كبير ومستقل في خط المرشح ينبغي عدم فقده عند المصالحة، لكن جمع الفرعين مباشرة **متعارض فعليًا**: `git merge-tree` أظهر تعارضات محتوى في 11 مسارًا رئيسيًا تشمل `server.ts`, `App.tsx`, flags، PDF viewer، i18n، وAI gateway. يلزم دمج انتقائي واعٍ بالمعمارية، وليس اعتماد طرف كامل كأساس إنتاج.

**حاجز مانع:** AI في مصدر `main` يجب ألا يعود إطلاقًا. في `5db0ce9:server.ts` يوجد عميل Gemini عبر `GEMINI_API_KEY`، endpoint/معالجة AI وتسلسل أسماء نماذج. أما خط review فيغلق AI في runtime ويُظهر رفضًا صريحًا؛ توثيق `116268b` يضيف boundary إداريًا وفحوصًا. يجب الحفاظ على الإغلاق وعدم إعادة أي مسار أو مفتاح/مزود AI من `main` عند استعادة مزايا أخرى.

4. **`5db0ce9` — تغليف Hostinger runtime بأصول الإنتاج:** ضبط مسارات/تضمين assets في runtime وملفات إعداد. **استعادة مشروطة:** طريقة تضمين static assets ومساراتها فقط إذا أثبتت الاختبارات توافقها؛ لا تنقل `server.ts` بالكامل لأن به AI محظورًا.

## ما يقابله في المرشح

الفرع `126bee8` يتضمن تغييرات PDF preview/إصلاحات وتجهيز توثيق حواجز الإصدار (`c5125c8`, `126bee8`). ثم `116268b` يضيف مراجعة أمان إعدادات AI، boundary server وtests، ويغلق AI في `server.ts` و`src/services/aiGateway.ts`. توجد أيضًا تغيرات مستقلة في PDF study/layout، رفع/تخزين المستندات المحلية، صفحات التقدم، واختبارات PDF/i18n. ينبغي الحفاظ عليها وعدم محوها باسترجاع نسخ `main` من الملفات المتداخلة.

## تعارضات مانعة/مخاطر الدمج

فحص `git merge-tree --write-tree 126bee8 5db0ce9` للقراءة فقط (لم يكتب index أو شجرة عمل) أظهر تعارضات محتوى في:

`package.json`, `server.ts`, `src/App.tsx`, `src/config/featureFlags.ts`, `src/features/book-viewer/PdfPageView.tsx`, `src/features/book-viewer/PdfViewer.tsx`, `src/i18n/ar/common.ts`, `src/i18n/en/common.ts`, `src/pages/AddBook.tsx`, `src/services/aiGateway.ts`, `src/services/pdfService.ts`.

هذه ليست تعارضات نصية هامشية فقط:

- **مصدر AI:** تعارض `server.ts` و`aiGateway.ts` أمني مانع؛ لا تعِد تنفيذ Gemini أو أي مزود AI من `main`، ولا تعِد `GEMINI_API_KEY` أو مفاتيح سرية للعميل/الخادم. أبقِ الفشل المغلق وحواجز الإدارة.
- **layout / runtime:** `server.ts`, package/build assets ومسارات static من main تتقاطع مع runtime المرشح. لا تنتقِ ملفات أوامر النشر بمعزل عن عقدة البناء، مسارات المخرجات، اختبارات التشغيل، وحالة الإصدار.
- **src / i18n / flags:** موارد الترجمة العربية والإنجليزية، أنواع i18n، واجهة التطبيق، وflags متغيرة على الطرفين. الدمج الآلي قد يفقد PDF-study أو يخلق مفاتيح ناقصة/أعلامًا متضاربة؛ يلزم تسوية واعية بالميزات وإضافة اختبارات مفاتيح/لغات.
- **PDF:** `PdfViewer`, `PdfPageView`, `pdfService` متنازع عليها؛ احفظ تدفق preview/layout/selection الخاص بالمرشح مع مراجعة أي تحسينات main على حدة.
