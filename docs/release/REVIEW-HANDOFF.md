## ما يمنع الإصدار

1. غياب بصمة حزمة الإنتاج المرتبطة بمصدر موثوق؛ سجل Hostinger لا يكفي.
2. اختلاف `noon.roubwx.com` الوارد بالتكليف عن `noon.roubex.com` في الاستضافة.
3. الفرع المحلي القديم لا يمثل main البعيد الحالي؛ يلزم التوفيق الموثق قبل اختيار أساس إنتاج.
4. تغليف runtime واختبار حزمة الخادم على staging لم يُحسما؛ بناء الواجهة لا يثبت جاهزية Hostinger.
5. موافقة جينو على التغييرات الدقيقة وSHA والرابط وخطة الرجوع لم تحصل بعد.

لم يُغيَّر main ولم يُنفذ نشر أو تعديل بيانات إنتاجية أو أسرار أو حسابات. النسخة الاحتياطية الأصلية وكل التعديلات السابقة محفوظة. المراجعة الأولية السريعة لا تحل محل هذا التدقيق على SHA؛ أي ملاحظات أولية توحي بأن التخزين والتقدم خارج npm test صُححت بالتحقق من الاستدعاءات المباشرة.

## طلب اختبار Gemini المنفصل

ورد تفويض لاحق باستخدام مفتاح محفوظ في اختبار خاص فقط. لا يشمل هذا التفويض إعادة تمكين AI في مرشح الإصدار أعلاه، ولا الإنتاج، ولا إرسال بيانات طلاب أو قاصرين. يجب أن يكون المختبر منفصلًا، والمفتاح في ذاكرة عملية الخادم وحدها، لا في ملفات المستودع أو JavaScript العميل أو إعدادات الإنتاج. واجهة اتصال محدودة بمواد اصطناعية ليست قبولًا لميزة AI الكاملة أو رفعًا لحاجز أهلية القاصرين.
