# أول شريحة حسابات وفصول حقيقية — محلية فقط

هذه الشريحة تعمل بقاعدة SQLite دائمة على الجهاز الذي يشغّل خادم Node، وليست واجهة لاختيار دور. لا تحتاج حساب خدمة أو بطاقة أو تفعيل فوترة. الحسابات مغلقة افتراضيًا، وتفعيلها يجبر الخادم على الاستماع إلى `127.0.0.1` فقط. المطلوب Node.js 24 أو أحدث؛ تستخدم الشريحة `node:sqlite` المدمج ولا تضيف مزودًا خارجيًا.

## المسار الذي تنفّذه

1. مشغّل الجهاز يهيّئ مدرسة وحساب مديرها عبر أمر محلي، لا عبر تسجيل عام أو ترقية دور من المتصفح.
2. مدير المدرسة يدخل بكلمة مرور، وينشئ فصلًا، ويصدر دعوة أحادية الاستخدام لمعلم أو طالب. تُنسخ الدعوة يدويًا؛ لا ترسل رسائل بريد أو تربط خدمة خارجية.
3. صاحب الدعوة ينشئ حسابه؛ المدرسة والفصل والدور تأتي من الدعوة المخزنة على الخادم، لا من اختيار المستخدم.
4. المعلم يرى فصوله فقط، ويكلف فصلًا بقراءة عنوان ونطاق صفحات. لا يرفع كتابًا أو ملف PDF.
5. الطالب يرى تكليفات فصله، ويسجل الإتمام. يسجّل الخادم هوية الطالب والوقت؛ لا يقبل `studentId` أو حالة أو وقتًا يرسلها العميل.
6. معلم الفصل يقرأ الإتمامات. معلم فصل آخر أو مدرسة أخرى لا يستطيع الوصول حتى بتغيير معرّفات URL. مدير المدرسة له رؤية إشرافية داخل مدرسته، والطالب يرى إتماماته فقط.

الإتمام إقرار من الطالب، وليس إثباتًا آليًا بأنه قرأ الصفحات. هذه الشريحة لا تولّد أسئلة أو تستخدم AI.

## تشغيل آمن ببيانات مصطنعة

نفّذ من هذا الـworktree المستقل. لا تستخدم بيانات طالب حقيقي. اختر مجلدًا خاصًا **خارج مجلد التطبيق**؛ يرفض الإعداد قاعدة داخل ملفات المشروع أو `public` أو `dist`، بما فيها التحويل عبر روابط المجلدات.

```bash
export NOON_LOCAL_ACCOUNTS_DB="$HOME/.local/share/noon-local-test/accounts.sqlite"
# كلمة المرور لا تُوضع في وسيط أمر أو ملف داخل Git. القراءة التالية لا تطبعها.
read -r -s -p 'كلمة مرور مدير الاختبار (12–128 حرفًا): ' NOON_BOOTSTRAP_PASSWORD
printf '\n'
printf '%s' "$NOON_BOOTSTRAP_PASSWORD" | npm run accounts:bootstrap -- test-school 'مدرسة مصطنعة' test-admin 'مدير اختبار'
unset NOON_BOOTSTRAP_PASSWORD

NOON_ACCOUNTS_LOCAL=1 PORT=3000 npm start
```

افتح `http://127.0.0.1:3000/accounts` على جهاز الخادم. رمز المدرسة في المثال `test-school`. شارك رمز المدرسة مع رمز الدعوة محليًا. لا توجد كلمة مرور افتراضية، ولا صفحة إعداد مفتاح AI، ولا رابط دعوة يحمل الرمز في عنوان URL.

قاعدة البيانات وملفاتها الجانبية بيانات حساسة؛ ليست جزءًا من Git. تعطيل الميزة لا يحذفها. لحذف بيانات الاختبار، أوقف الخادم ثم احذف قاعدة الاختبار من المجلد الخاص الذي اخترته. لا تحذف قاعدة أو تستبدلها أثناء تشغيل الخادم.

## الحماية والحفظ

كلمات المرور مجزأة بـscrypt مع ملح عشوائي لكل حساب؛ رموز الجلسات والدعوات مخزنة كـSHA-256 لا كقيم خام. الجلسة عشوائية وصلاحيتها ثماني ساعات، وملف تعريف الارتباط `HttpOnly; SameSite=Strict; Path=/api`. عدم إضافة `Secure` مقصود لهذا التشغيل عبر HTTP على loopback فقط، وليس إعدادًا مناسبًا للإنتاج.

الطلبات المعدّلة تحتاج Origin مطابقًا، وتحتاج أيضًا رمز CSRF المرتبط بالجلسة، ما عدا الدخول وقبول الدعوة اللذين يتحققان من Origin وتحديد المعدل. يعاد فحص الهوية والدور والمدرسة وعضوية الفصل خادميًا. الاستجابات `no-store` ولا تدخل بيانات الحسابات في PWA cache. لا تخزّن الواجهة الحسابات أو الجلسات أو الدعوات في localStorage أو IndexedDB، وتُزال حالة مساحة الحساب عند الخروج أو انتهاء الجلسة.

دعوة واحدة تنشئ حسابًا واحدًا وعضوية فصل واحدة، وصلاحيتها 24 ساعة؛ إعادة استخدامها مرفوضة. الحساب في هذه الشريحة تابع لمدرسة واحدة، ولا توجد ترقية إدارية أو تغيير دور أو نقل مدارس عبر API. الحساب المباشر الذي ينشئه مدير المدرسة لا يدخل فصلًا تلقائيًا؛ مسار الدعوة هو مسار الشريحة الصفية.

**سياسة تعارض الإتمام: أول حفظ يفوز.** يوجد قيد فريد لكل طالب وتكليف. تكرار الإرسال، حتى بمفتاح جديد بعد إعادة فتح الصفحة، يعيد الإتمام نفسه وتوقيته ولا يضاعفه أو يعيد كتابته. الواجهة تعرض جاري الحفظ / محفوظ / فشل، وتحتفظ بمفتاح المحاولة في ذاكرة الصفحة لإعادة المحاولة. لا تدّعي نجاحًا قبل رد الخادم. لا يوجد طابور offline دائم: عند انقطاع الشبكة يجب إعادة المحاولة؛ بعد إعادة الدخول يمكن قراءة الحقيقة من الخادم ثم إعادة الإرسال بأمان.

## ما لا تفعله هذه الشريحة

ملفات PDF وملاحظات المكتبة القديمة تبقى في مخازن المتصفح الحالية، ولا يقرأها مسار الحسابات ولا يرفعها ولا يشاركها. أرقام صفحة التقدم القديمة التجريبية ليست تقارير حسابات، ولم تُستخدم في تقارير الفصول. المكتبة الحالية تخزين جهاز وليست مساحة خاصة بكل حساب؛ لذا **لم يكتمل عزل مكتبة/PDF/ملاحظات الحسابات على جهاز مشترك**. لا تدخل بيانات حقيقية في المكتبة اعتمادًا على تسجيل الدخول الجديد. حالة الحسابات الصفية نفسها منفصلة وممسوحة عند تبديل الحساب.

لا توجد دعوة بريدية، أو استعادة كلمة مرور، أو تحقق بريد/هاتف، أو موافقات أولياء الأمور، أو إدارة دورة حياة الطالب، أو سجلات تدقيق تشغيلية، أو نسخ احتياطية مجرّبة، أو Secret Manager. لا توجد مزامنة عامة، ولا استضافة، ولا نشر أو push أو merge.

## قرار التخزين والاستضافة قبل أي استخدام حقيقي

لا يوجد مانع مالي يمنع اختبار الشريحة محليًا: SQLite متوفرة بالفعل ولا تحتاج خدمة. أما الوصول من **جهاز فعلي ثانٍ** خارج جهاز الخادم فغير مفعّل عمدًا. السياقات/الجلسات المستقلة في الاختبارات تحاكي عميلين على الخادم المحلي نفسه؛ ليست ادعاءً بنشر متعدد الأجهزة.

قبل ربط أجهزة حقيقية يلزم قرار صريح بشأن بيئة استضافة خادم وقاعدة دائمة، HTTPS، إدارة المفاتيح والأسرار، النسخ الاحتياطي والاستعادة، مناطق البيانات والاحتفاظ بها، التحقق والاستعادة والإلغاء، والمتطلبات القانونية لحسابات القاصرين. SQLite الحالية مناسبة لشريحة محلية أحادية العملية؛ لا نفترض أنها قرار قاعدة إنتاج موزعة. يلزم كذلك تصميم ملكية وترحيل/عزل مخازن PDF والملاحظات المحلية قبل دمج واجهة المكتبة في حسابات متعددة. لا تفعّل هذه الشريحة على النطاق الحي بتغيير مفتاح بيئة فحسب؛ الإعداد يرفض أصلًا عامًا ويربطها محليًا عمدًا.

## الاختبارات

```bash
npm run test:accounts
npm run lint
npm test
```

اختبارات التكامل تستخدم مجلدات SQLite مؤقتة وبيانات مصطنعة فقط. تغطي المصادقة وCSRF وOrigin وتصعيد الدور وعزل المدارس والفصول والطلاب، استخدام الدعوة مرة واحدة، إعادة الإرسال، جلسة مستقلة، وإعادة فتح قاعدة البيانات. بوابة `npm test` تحتفظ باختبارات إغلاق المساعد وPDF وPWA السابقة أيضًا.
