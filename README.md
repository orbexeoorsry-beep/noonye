# نون | Noon Learning

منصة تعلم عربية ذكية تعرض الكتاب الأصلي كما هو عبر عارض PDF حقيقي، مع مساعد فوري يساعد الطالب على فهم الفقرات والصور والخرائط والجداول والمعادلات والمسائل دون تغيير شكل الكتاب أو ترتيب صفحاته.

---

## 1. طريقة تشغيل المشروع (Getting Started)

المشروع مبني باستخدام **React 19 + TypeScript + Vite + Tailwind CSS v4 + PDF.js**.

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# تشغيل حزمة الاختبارات الآلية الشاملة
npm test

# فحص الأخطاء (Linting & Typecheck)
npm run lint

# البناء النهائي للإنتاج (Production Build)
npm run build
```

## 3. وظائف عارض PDF الحقيقي (All 18 Functions Implemented)

1. **عرض صفحة PDF الحالية**: تصيير دقيق لملف PDF الأصلي على عنصر Canvas بجودة فائقة (High-DPI).
2. **الانتقال إلى الصفحة السابقة**: زر تفاعلي مع تعطيل ذكي عند بلوغ الصفحة الأولى.
3. **الانتقال إلى الصفحة التالية**: زر تنقل سلس مع تعطيل عند الصفحة الأخيرة.
4. **إدخال رقم صفحة للانتقال إليها**: حقل إدخال مباشر يدعم الضغط على Enter مع التحقق التلقائي من النطاق.
5. **عرض رقم الصفحة الحالية وإجمالي الصفحات**: مؤشر واضح بأرقام مفهرسة (`صفحة X من Y`).
6. **التكبير (Zoom In)**: تكبير تدريجي يصل حتى 250%.
7. **التصغير (Zoom Out)**: تصغير تدريجي حتى 50%.
8. **العودة إلى الحجم الطبيعي**: إعادة الضبط الفورية للحجم الأصلي 100%.
9. **ملاءمة الصفحة مع عرض الهاتف (Fit Width)**: حساب أبعاد الشاشة تلقائياً لجعل الصفحة تملأ العرض بأقصى وضوح.
10. **ملاءمة الصفحة مع ارتفاع الشاشة (Fit Height)**: ضبط الارتفاع ليتناسب مع نافذة العرض.
11. **التحريك داخل الصفحة عند التكبير (Pan & Drag)**: سحب سلس باللمس أو الماوس مع تغيير المؤشر إلى `grab/grabbing`.
12. **وضع ملء الشاشة (Fullscreen)**: دعم كامل لخاصية Fullscreen API للقراءة بدون مشتتات.
13. **زر فتح أدوات نون**: نافذة Bottom Sheet منسدلة بسلاسة على الهاتف، ولوحة جانبية على الكمبيوتر.
14. **حفظ آخر صفحة قرأها المستخدم محليًا**: حفظ فوري ومستمر في IndexedDB و LocalStorage عند تقليب الصفحات.
15. **استعادة آخر صفحة تلقائياً**: العودة لنفس الصفحة التي توقف عندها الطالب عند إعادة فتح الكتاب.
16. **إظهار رسالة تحميل واضحة**: مؤشر تحميل مع نص عربي صريح أثناء تصيير الصفحة.
17. **إظهار رسالة عربية مفهومة إذا كان الملف غير صالح**: إشعار دقيق إذا كان الملف تالفاً أو ليس PDF.
18. **إظهار رسالة إذا كان الملف كبيرًا أو تعذر فتحه**: تنبيه في حال تجاوز سعة ذاكرة المتصفح مع زر إعادة المحاولة.
- **زر حذف الكتاب والبيانات المحلية**: إمكانية إزالة الكتاب من الجهاز وتفريغ مساحته من IndexedDB بنقرة واحدة وتأكيد حماية.

## 4. طبقة التفاعل المستقبلية (Smart Interaction Overlay)

طبقة شفافة موضوعة فوق صفحة PDF لا تُغير أي بكسل في الكتاب، تتيح:
- تحديد الفقرات النصية.
- تحديد الرسوم التوضيحية البيولوجية.
- تحديد المعادلات الرياضية.
- تحديد الخرائط والجداول الإحصائية.
- فتح أدوات نون الذكية فور النقر على أي عنصر محدد مع نقل سياقه.
- إمكانية إخفاء أو تفعيل طبقة التحديد بنقرة واحدة من شريط الأدوات.

---

## 5. التخزين المحلي الآمن (LocalDocumentStore via IndexedDB)

- تُخزن ملفات PDF الثنائية (ArrayBuffer) داخل **IndexedDB** حصراً على جهاز الطالب.
- لا يتم استخدام localStorage لتخزين الملفات الكبيرة منعاً لتجاوز حدود التخزين.
- لا يتم رفع أي ملف إلى أي خادم خارجي (أمان وخصوصية 100%).
- يتم تخزين البيانات الوصفية فقط (الاسم، الحجم، عدد الصفحات، آخر صفحة، تاريخ الفتح) لإدارة المكتبة.

## 6. نتائج الاختبارات الآلية (Automated Verification)

تم إعداد وتشغيل حزمة اختبارات شاملة تشمل 19 فحصاً آلياً تغطي:
- فتح ملفات PDF الصالحة وتوليد الوثائق التعليمية الأصلية.
- رفض الملفات غير الصالحة أو التالفة.
- فحص منطق الانتقال وحدود الصفحات (Bounds checking).
- التحقق من إدخال أرقام الصفحات الصالحة ورفض الأرقام الخاطئة.
- معادلات التكبير والتصغير وملاءمة العرض والارتفاع.
- اختبار عمليات IndexedDB (الحفظ، الاسترجاع، تحديث الصفحة، والحذف).
- التأكد التام من خلو الكود من أي مفاتيح برمجية (API Keys).

## 7. طريقة إضافة لغة جديدة (Adding a New Language)

لإضافة لغة جديدة إلى مشروع نون (مثل الفرنسية `fr`):
1. أنشئ مجلدًا جديدًا باسم رمز اللغة داخل `src/i18n/{code}/` (مثل `src/i18n/fr/`) يحتوي على ملفات الميزات المنفصلة: `common.ts`، `library.ts`، `bookViewer.ts`، `localDocuments.ts`، `selection.ts`، `aiAssistant.ts`، `guidedMath.ts`، `scienceAnalysis.ts`، `errors.ts`، و`settings.ts`، ومجمعة في `index.ts`.
2. سجّل اللغة الجديدة في `src/i18n/index.ts` عبر استيرادها وإضافتها إلى `supportedLanguages` أو استدعاء `registerLanguage(code, dictionary, meta)`.

## 8. نظام التحكم بالميزات (Feature Flags)

يمكن تشغيل أو إيقاف الميزات من ملف مركزي واحد دون تعديل مكونات الواجهة:

- **ملف الإعدادات:** `src/config/feature-flags.ts`
- **الدالة المساعدة:** `isFeatureEnabled('lessonSummaryEnabled')`

لتشغيل أو إيقاف أي ميزة، غيّر قيمتها بين `true` و `false` داخل الكائن `featureFlags` في `src/config/feature-flags.ts`:

```ts
export const featureFlags: FeatureFlags = {
  localBooksEnabled: true,       // الكتب المحلية ورفع ملفات PDF
  lessonsEnabled: true,          // شريط الدروس والتنقل بينها
  lessonTestsEnabled: true,      // اختبارات الدروس
  lessonSummaryEnabled: false,   // ملخصات الدروس
  selectionEnabled: false,       // أداة التحديد على صفحات الكتاب
  aiAssistantEnabled: false,     // مساعد نون الذكي
  guidedMathEnabled: false,      // التحليل الموجّه للمسائل الرياضية
  scienceAnalysisEnabled: false, // تحليل الصور والأشكال العلمية
  englishLanguageEnabled: true,  // دعم اللغة الإنجليزية وتبديل اللغة
};
```

عند إغلاق أي ميزة (`false`)، يختفي زرها ورابطها تلقائيًا ولا يمكن تشغيلها عبر رابط مباشر دون أن يتعطل باقي التطبيق.
