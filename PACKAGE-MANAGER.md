# Package manager and deployment install

This repository uses **npm** as its sole lockfile authority because Hostinger's project metadata installs with npm and this branch has no Bun runtime in its supported deployment path. `package-lock.json` is generated by npm from `package.json`; clean installs use `npm ci` (not a mutable install). The previous `bun.lock` was stale and did not contain `playwright-core`; it was removed rather than edited by hand or retained as a misleading alternate lockfile.

`playwright-core@1.64.1` is published on the public npm registry. Browser binaries are not installed by this package: test setup uses the system Chromium executable (currently `/usr/bin/chromium`).
