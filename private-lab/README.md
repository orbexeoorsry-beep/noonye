# مختبر Gemini الخاص — نون

هذا مختبر اتصال منفصل للمطور، وليس إعادة تفعيل AI في واجهة نون أو الإصدار. مشتق من فرع المراجعة بعد توثيق نتيجته `126bee8`، ويعمل على المنفذ 4180 خارج نسخة PDF في المنفذ 4173. لم تُغيّر شيفرة التطبيق أو feature flags أو الخادم الإنتاجي.

## شروط القبول والنتيجة

1. المفتاح في ذاكرة الخادم فقط: يأخذه `server.mjs` من `NOON_GEMINI_TEST_KEY` ويحذفه من process.env بعد القراءة. لا ملفات env ولا key في HTML أو Git أو السجلات. يرفض التشغيل في `NODE_ENV=production`.
2. الدخول برابط قدرة عشوائي 256-bit محفوظ خارج المشروع بصلاحية 0600، ثم cookie HttpOnly/SameSite=Strict وSecure عبر أصل HTTPS المتوقع. الجلسة تنتهي بعد ساعتين من التشغيل، والعنوان وحده دون جلسة يرجع 401. لا تُلصق رابط الدخول في هذه الوثيقة أو المستودع.
3. API يفرض Origin وJSON، ويقبل قيم `tool` و`sample` المحددة فقط. يمنع النص الحر والرفع وبيانات الطلاب، ويحدد الجسم بـ512 بايت. فاصل خمس ثوانٍ، طلب واحد نشط، عشرة طلبات إجمالًا طوال العملية. لا إعادة محاولة أو fallback آلي.
4. قرأ الخادم قائمة نماذج Google الحية واختار النموذج المتاح `models/gemini-3.5-flash-lite`. طلب اصطناعي فعلي لحل `2x+3=11` أعاد HTTP 200 ونصًا صحيحًا `x=4`. ثم اختُبر زر الواجهة على الرابط HTTPS بعينة الأسموزية وظهر «تم الاتصال بـ Gemini» مع النص. استُخدم طلبان من حد عشرة عند التوثيق.
5. اختبارات الحماية: بلا جلسة 401؛ origin غير مصرح 403؛ حقل نص إضافي 400؛ HTML دون مفتاح؛ فتح رابط الجلسة 200. النتيجة الآلية في `evidence/connection-test.json`.
6. مراجعة أمنية مستقلة للملفين فقط لم تجد مانعًا عالي الخطورة واضحًا. تحفظاتها: الاعتماد على حماية الوكيل وصحة Host، وحدود الطلبات في عملية واحدة، وعدم إثبات إعداد الجدار الناري من الشيفرة وحدها. لم يدّع المراجع فحص المفتاح أو بيئة الاستضافة؛ اختبار الاتصال الفعلي موثق أعلاه بصورة منفصلة.

## حدود النطاق

واجهة بعينات اصطناعية ثابتة: شرح وتبسيط وتلميح واختبار. ليست اختبار رفع PDF إلى Gemini أو مراجعة لمخرجات المنهج. لا تغيّر مانع أهلية القاصرين أو متطلبات امتثال AI قبل إتاحته للطلاب. لا نعدّ الإجابات مولدًا موثقًا أو تقييمًا تربويًا معتمدًا. قد تضيف إجابة النموذج استنتاجات؛ ليست نسخة من النص المستخرج فقط كما في مراجعة PDF.

الواجهة تتصل بـ`/api/test` المحلي، والخادم يرسل العينة الاصطناعية إلى Google. لا يعني وصف «محلي» أن الاستدلال يجري دون شبكة. لا استدعاءات خارجية من المتصفح نفسه أو خطوط خارجية.

## التشغيل والإيقاف

تتطلب العملية Node حديثًا مع fetch وتوفير متغير اختبار مؤقت بواسطة المشغّل الآمن؛ لا تضع المفتاح في الأمر المحفوظ أو ملفات المشروع. تشغيل الخادم: `node private-lab/server.mjs`. لا تستخدمه في Hostinger أو الإنتاج أو حاوية عامة، ولا تعاود تشغيله تلقائيًا لتجديد حصة الطلبات. ملف رابط الدخول خارج Git عمدًا.

للرجوع: إيقاف عملية مختبر المنفذ 4180 فقط؛ تنتهي صلاحية رابطها وجلساتها، ولا يلزم أي تغيير لنسخة PDF أو الإنتاج. العملية ترفض الطلبات بعد انقضاء ساعتين ولا تجدّد نفسها. لا تدوير مفتاح ولا تعديل حسابات أو إعدادات إنتاج.

مرجع API: [generateContent](https://ai.google.dev/api/generate-content) و[models.list](https://ai.google.dev/api/models). لا تُرسل بيانات شخصية أو أي ملفات للمختبر.
